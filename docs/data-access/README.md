# Colvera data-access package

These are concise non-commercial research request briefs, not submitted requests. They keep the project focused on datasets capable of answering a clinically meaningful longitudinal question rather than accumulating disconnected benchmarks.

| Brief | Why it matters | Immediate experiment |
|---|---|---|
| [622-patient longitudinal MRI cohort](622-longitudinal-mri-cohort.md) | Best near-term bridge: paired pre/post multiparametric MRI, CEA, pCR, internal/external cohorts | Current-only vs paired longitudinal MRI for pCR |
| [OPRA](opra.md) | Prospective watch-and-wait target with response assessment and regrowth relevance | Multimodal surveillance trajectory → local-regrowth outcome |
| [IWWD](iwwd.md) | Large international watch-and-wait registry | Generalizable surveillance trajectory study |
| [Lambregts serial-MRI cohort](lambregts-serial-mri.md) | Exact small local-regrowth question with serial T2/DWI | Current MRI vs previous + current MRI for local-regrowth detection |

All approved data must be stored outside Git, handled only under the owner’s agreement/oversight, represented using the longitudinal data contract, and never used in the public MMP until the owner approves the presentation scope.
